# Flow Configuration Blueprint

## WhatNext Vision Motors – Salesforce CRM

This blueprint is based on the project documentation.

---

## 1. Auto Assign Dealer Flow

### Objective
Create a record-triggered flow that assigns a dealer to a vehicle order based on customer location.

### Flow Type
- Record-Triggered Flow

### Object
- Vehicle Order (`Vehicle_Order__c`)

### Trigger
- Trigger when a record is created

### Entry Condition
- `Status__c` Equals `Pending`

### Flow Elements

1. **Start**
   - Object: Vehicle Order
   - Trigger: When a record is created
   - Condition: `Status__c = Pending`

2. **Get Customer Information**
   - Use the Customer ID from the vehicle order.
   - Retrieve the customer's information.

3. **Get Nearest Dealer**
   - Use the customer's address/location.
   - Retrieve the nearest dealer.

4. **Update Records – Assign Dealer**
   - Update the Vehicle Order.
   - Assign the selected dealer to the order.

5. **End**

### Flow Name
`Auto Assign Dealer`

### Final Action
Save and activate the flow.

### Flow Sequence

```text
Vehicle Order Created
        ↓
Status = Pending?
        ↓
Get Customer Information
        ↓
Get Nearest Dealer
        ↓
Assign Dealer to Order
        ↓
       End
```

## 2. Test Drive Reminder Flow

### Objective
Send an email reminder to the customer one day before a scheduled test drive.

### Flow Type
- Record-Triggered Flow

### Object
- Vehicle Test Drive (`Vehicle_Test_Drive__c`)

### Trigger
- Trigger when a record is created or updated

### Entry Condition
- `Status__c` Equals `Scheduled`

### Flow Elements

1. **Start**
   - Object: Vehicle Test Drive
   - Trigger: When a record is created or updated
   - Condition: `Status__c = Scheduled`

2. **Scheduled Path**
   - Schedule the path for one day before `Test_Drive_Date__c`.

3. **Get Customer Information**
   - Retrieve the customer's information.

4. **Send Email**
   - Recipient: Customer's `Email__c`
   - Subject: `Reminder: Your Test Drive is Tomorrow!`

5. **End**

### Flow Sequence

```text
Test Drive Created/Updated
        ↓
Status = Scheduled?
        ↓
Scheduled Path
(1 day before Test_Drive_Date__c)
        ↓
Get Customer Information
        ↓
Send Email Reminder
        ↓
       End
```

## 4. Salesforce Navigation

### Auto Assign Dealer

```text
Setup
  → Flows
    → New Flow
      → Start From Scratch
        → Record-Triggered Flow
```

Configure the Vehicle Order object, trigger, entry condition, Get Records elements, Update Records element, then save and activate as `Auto Assign Dealer`.

### Test Drive Reminder

```text
Setup
  → Flows
    → New Flow
      → Start From Scratch
        → Record-Triggered Flow
```

Configure the Vehicle Test Drive object, trigger, entry condition, scheduled path, customer lookup, and Send Email action, then save and activate the flow.

## Source Notes

The project documentation specifies the flow objectives, objects, triggers, entry conditions, major flow elements, and email subject. It does **not** provide the detailed Salesforce configuration values for every Get Records filter, exact dealer-distance calculation, or every field mapping. Those details should therefore be configured separately rather than assumed from this blueprint.
